BRINE: RELAY NINE is an original single-player tactical FPS set on a coastal relay breakwater. Move through the dock and relay lanes, fight bot squads, purchase armor and equipment, and contest the signal charge objective.

## Run it

Requires Node.js 22.18+ and a desktop browser with WebGL 2.

```sh
node serve.ts
```

Open http://localhost:8080. Controls: WASD move, mouse look, click fire, R reload, B requisition, E interact, 1/2/3 weapon select, G smoke, Shift sprint, Ctrl crouch, Escape pause.
